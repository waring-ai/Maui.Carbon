# Font sources

IBM Plex static TrueType fonts, SIL Open Font License 1.1 (see OFL.txt, taken from the release zips).
Copied into src/Maui.Carbon/Resources/Fonts/ from the IBM/plex GitHub release assets:

- IBMPlexSans-Light.ttf, IBMPlexSans-Regular.ttf, IBMPlexSans-SemiBold.ttf: @ibm/plex-sans@1.1.0 (ibm-plex-sans.zip, fonts/complete/ttf)
- IBMPlexMono-Regular.ttf: @ibm/plex-mono@2.5.0 (ibm-plex-mono.zip, fonts/complete/ttf)
- IBMPlexSerif-Light.ttf, IBMPlexSerif-Regular.ttf: @ibm/plex-serif@2.0.0 (ibm-plex-serif.zip, fonts/complete/ttf)

The npm packages of the same versions only ship woff/woff2, hence the GitHub release zips.
